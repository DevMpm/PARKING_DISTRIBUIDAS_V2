Módulo de Role-Permissions (/roles/:roleId/permissions/:permissionId)

Asignar Permiso a Rol (POST /roles/:roleId/permissions/:permissionId)

CP1.1 Asignar permiso a rol ok
Precondiciones: Token JWT con permiso ROLES_UPDATE, rol existente y permiso existente no asignados previamente.
Entrada: roleId (UUID) y permissionId (UUID) válidos como parámetros de ruta.
Verificar:
1. Código de respuesta 201
2. Confirmación de asignación exitosa.
3. Consultar permisos del rol (GET /roles/:roleId/permissions) para verificar que el permiso está incluido.

CP1.2 Asignar permiso a rol duplicado (Ya asignado)
Precondiciones: Token JWT con permisos suficientes y relación roleId-permissionId ya existente.
Entrada: Mismos roleId y permissionId válidos.
Verificar:
1. Código de respuesta 409 (o 400 según manejo de duplicados)
2. Mensaje de error indicando que la asignación ya existe.

CP1.3.1 Asignar permiso - Rol not found
Precondiciones: Token JWT con permisos suficientes y permissionId válido.
Entrada: roleId UUID inexistente y permissionId válido.
Verificar:
1. Código de respuesta 404
2. Mensaje de error de rol no encontrado.

CP1.3.2 Asignar permiso - Permiso not found
Precondiciones: Token JWT con permisos suficientes y roleId válido.
Entrada: roleId válido y permissionId UUID inexistente.
Verificar:
1. Código de respuesta 404
2. Mensaje de error de permiso no encontrado.

CP1.3.3 Asignar permiso - UUID inválido en parámetros
Precondiciones: Token JWT con permisos suficientes.
Entrada: roleId o permissionId con formato no UUID (ej. "abc", "123").
Verificar:
1. Código de respuesta 400
2. Mensaje de error por formato de UUID inválido.

Remover Permiso de Rol (DELETE /roles/:roleId/permissions/:permissionId)

CP2.1 Remover permiso de rol ok
Precondiciones: Token JWT con permiso ROLES_UPDATE y relación roleId-permissionId existente.
Entrada: roleId y permissionId válidos como parámetros.
Verificar:
1. Código de respuesta 200
2. Confirmación de remoción exitosa.
3. Consultar permisos del rol (GET /roles/:roleId/permissions) para confirmar que ya no aparece.

CP2.2 Remover permiso de rol not found (No asignado)
Precondiciones: Token JWT con permisos suficientes.
Entrada: roleId y permissionId válidos pero sin asignación previa entre ellos.
Verificar:
1. Código de respuesta 404
2. Mensaje de error indicando que la asignación no existe.

CP2.3 Remover permiso - UUID inválido
Precondiciones: Token JWT con permisos suficientes.
Entrada: Parámetros con formato UUID inválido.
Verificar:
1. Código de respuesta 400
2. Mensaje de error.

Listar Permisos de un Rol (GET /roles/:roleId/permissions)

CP3.1 Listar permisos de rol ok
Precondiciones: Token JWT con permiso ROLES_READ, rol existente con permisos asignados.
Entrada: roleId válido como parámetro de ruta.
Verificar:
1. Código de respuesta 200
2. Cantidad de permisos obtenidos en la consulta asociados al rol.

CP3.2 Listar permisos de rol sin resultados (Rol sin permisos)
Precondiciones: Token JWT con permiso ROLES_READ y rol existente sin permisos asignados.
Entrada: roleId válido.
Verificar:
1. Código de respuesta 200 (o 404 según diseño) y cantidad de registros (0).

CP3.3 Listar permisos de rol - Rol not found
Precondiciones: Token JWT con permiso ROLES_READ.
Entrada: roleId UUID inexistente.
Verificar:
1. Código de respuesta 404
2. Mensaje de error de rol no encontrado.

CP3.4 Listar permisos de rol - UUID inválido
Precondiciones: Token JWT con permiso ROLES_READ.
Entrada: roleId con formato no UUID.
Verificar:
1. Código de respuesta 400
2. Mensaje de error.

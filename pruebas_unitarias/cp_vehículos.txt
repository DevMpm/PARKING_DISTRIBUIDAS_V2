Crear Vehículo

CP1.1 Crear vehículo tipo Auto ok
Precondiciones: Token JWT con roles suficientes (VEHICULOS_CREATE)
Entrada: JSON con tipo "Auto", idPropietario opcional y datos válidos de Auto (placa ABC-1234, marca Toyota, modelo Corolla, color Rojo, anio 2022, clasificacion Gasolina, numeroPuertas 4, capacidadMaletero 400)
Verificar:
1. Código de respuesta 201
2. Respuesta DTO con datos correctos del auto.
3. Buscar por Id para confirmar su existencia.

Obtener Vehículos (Múltiples resultados)

CP4.1 Obtener todos los vehículos ok
Precondiciones: Token JWT con roles suficientes (VEHICULOS_READ) y vehículos creados en el sistema.
Entrada: Ninguna (GET /vehiculos)
Verificar:
1. Código de respuesta 200
2. Cantidad de registros obtenidos en el array acorde al total existente.

CP4.2 Obtener vehículos por ID de propietario ok
Precondiciones: Token JWT con roles suficientes y vehículos asociados a un idPropietario específico.
Entrada: UUID de propietario como parámetro (GET /vehiculos/propietario/:idPropietario)
Verificar:
1. Código de respuesta 200
2. Cantidad de registros obtenidos coincidente con las asignaciones del propietario.

CP4.3 Obtener vehículos por ID de propietario sin resultados
Precondiciones: Token JWT con roles suficientes
Entrada: UUID de propietario sin vehículos asociados.
Verificar:
1. Código de respuesta 200 y cantidad de registros 0 (array vacío).

Obtener Vehículo (Único resultado)

CP5.1 Buscar vehículo por ID ok
Precondiciones: Token JWT con roles suficientes y un vehículo creado con UUID válido.
Entrada: UUID del vehículo como parámetro (GET /vehiculos/:id)
Verificar:
1. Código de respuesta 200
2. Datos de la respuesta coinciden exactamente con el vehículo buscado.

CP5.2 Buscar vehículo por ID no existente
Precondiciones: Token JWT con roles suficientes
Entrada: UUID inexistente.
Verificar:
1. Código de respuesta 404
2. Mensaje de error de vehículo no encontrado.

CP5.3 Buscar vehículo por placa ok

Entrada: Placa como parámetro (GET /vehiculos/placa/:placa)

1. Código de respuesta 200
2. Datos de la respuesta coinciden con el vehículo de esa placa.

CP5.4 Buscar vehículo por placa no existente

Eliminar y Reactivar Vehículo

CP7.1 Eliminar vehículo ok (Baja lógica)
Precondiciones: Token JWT con roles suficientes (VEHICULOS_DELETE) y un vehículo creado.
Entrada: UUID del vehículo como parámetro (DELETE /vehiculos/:id)
Verificar:
1. Código de respuesta 200
2. Buscar por Id para confirmar que el estado activo cambió a false (baja lógica).

CP7.2 Eliminar vehículo - Not Found
Precondiciones: Token JWT con roles suficientes
Entrada: UUID inexistente.
Verificar:
1. Código de respuesta 404
2. Mensaje de error.

CP8.1 Reactivar vehículo ok
Precondiciones: Token JWT con roles suficientes (VEHICULOS_UPDATE) y un vehículo previamente dado de baja (activo = false).
Entrada: UUID como parámetro y opcional idPropietario en el body (PATCH /vehiculos/:id/reactivar)
Verificar:
1. Código de respuesta 200
2. Datos de respuesta con activo = true.
3. Buscar por Id para confirmar reactivación.

CP8.2 Reactivar vehículo - Not Found
Precondiciones: Token JWT con roles suficientes
Entrada: UUID inexistente.
Verificar:
1. Código de respuesta 404
2. Mensaje de error.

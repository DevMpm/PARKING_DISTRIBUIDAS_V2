\casodeprueba{CP3}
{Crear evento de auditoría - Datos inválidos (DTO constraints)}
{Token JWT con rol y permisos suficientes (AUDITORIA\_CREATE).}
{JSON con datos inválidos por campo (casos CP3.1 - CP3.9):}
{\begin{enumerate} [leftmargin=*, nosep]
    \item CP3.1 Servicio inválido (menor a 7 caracteres, no comienza con 'ms-', o vacío)
    \item CP3.2 Acción inválida (acción no permitida o fuera de catálogo)
    \item CP3.3 Entidad inválida (minúsculas, espacios, o caracteres no permitidos)
    \item CP3.4 EntidadId inválido (formato UUID v4 no válido)
    \item CP3.5 Rol inválido (caracteres no permitidos o longitud incorrecta)
    \item CP3.6 Datos inválidos (no cumple con ser un objeto JSON)
    \item CP3.7 Usuario inválido (caracteres no permitidos o longitud incorrecta)
    \item CP3.8 IP inválida (formato IPv4 incorrecto o vacía)
    \item CP3.9 MAC inválida (formato de dirección MAC incorrecto)
    \item Código de respuesta 400
    \item Mensaje de error.
    \item Buscar por Id y verificar que no se creó el registro.
\end{enumerate}}
